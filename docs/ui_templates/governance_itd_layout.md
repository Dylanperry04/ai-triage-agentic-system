# UI Template: Governance / ITD Layout

## Target User

ITD/security admin, governance auditor, project supervisor.

## Layout Purpose

Centralise operational evidence:

1. audit dashboard and filters
2. governance policy checks
3. system status and RBAC role evidence
4. model artifact compatibility
5. retraining evidence
6. cost/runtime assumptions
7. maintainability and optional tooling status

## Strengths

- Best for auditability and deployment-readiness discussion.
- Keeps future/plugin/maintenance features out of the main clinical flow.
- Makes operational assumptions and missing approvals explicit.

## Limitations

- Not designed for front-line triage review.
- Requires RBAC controls so clinical roles do not see unrelated admin tools.

## Summit Use

Use this layout for governance, security, cost, audit, and deployment
conversation.
