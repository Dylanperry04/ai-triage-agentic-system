# UI Template: Dashboard-First Layout

## Target User

Researcher, clinical supervisor, governance auditor.

## Layout Purpose

Start with aggregate evidence:

1. model comparison table
2. recall/specificity charts
3. confusion matrix
4. ROC and precision-recall curves
5. class distribution and imbalance reports
6. audit activity dashboard

## Strengths

- Best for methodology review and performance trade-off discussion.
- Makes over-triage visible instead of showing recall alone.
- Supports questions about class imbalance and retraining evidence.

## Limitations

- Less efficient for reviewing a single patient case.
- Requires careful explanation so aggregate metrics are not confused with
  clinical approval.

## Summit Use

Use this layout when discussing model results, class imbalance, SMOTE/class
weights, and evaluation methodology.
