# UI Template: Clinician-First Workflow

## Target User

Triage nurse, ED doctor, clinical supervisor.

## Layout Purpose

Keep the main screen focused on the current case:

1. case input or case selector
2. ML estimate and Manchester-style display colour
3. explanation and caution signals
4. action buttons: accept, request more information, escalate, override where
   role-permitted

## Strengths

- Fastest layout for case-by-case review.
- Keeps clinical action buttons close to the assessment.
- Minimises dashboard and admin clutter for front-line users.

## Limitations

- Less useful for governance or model-performance discussion.
- Aggregate metrics are intentionally pushed to separate tabs.

## Summit Use

Use this layout when demonstrating the user journey from triage evidence to
clinician review action.
